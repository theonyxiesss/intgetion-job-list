# Навыки (таксономия) — как устроено

Модуль `src/modules/taxonomy`. ТЗ: [11-taxonomy.md](../tz/11-taxonomy.md).

## Что делает

Держит единый справочник навыков с категориями и синонимами. Свободный текст навыка приводится к одному виду и сопоставляется со справочником (`normalizeSkill`, `matchSkillSlug`, порог похожести `SKILL_SIMILARITY_THRESHOLD`). Незнакомый навык становится предложением, админ его сопоставляет или отклоняет. Навыки вакансии достаются из её текста (`service/extract-skills.ts`), старые вакансии дозаполняются кроном (`backfillJobSkills`). Справочник используют вакансии, анкета кандидата, подбор, фриланс, зарплаты.

## Маршруты и страницы

- Cron: `/api/cron/job-skills` в 40 минут каждого часа.
- Админка: `/admin/taxonomy`, API `/api/admin/taxonomy/suggestions` (+ `[id]/map`, `[id]/reject`) — через модуль admin ([admin.md](admin.md)).
- Выбор навыков в формах: `/profile/freelance/[id]/edit` и другие формы через модули jobs и candidates.
