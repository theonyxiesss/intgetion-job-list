# События (events aggregator)

> Живое ТЗ домена. Решение: [D413](../DECISIONS.md). Как в коде: [how-it-works/events.md](../how-it-works/events.md).

## 26.1 Что это

Отдельная вкладка «События»: предстоящие события Web3 и IT — саммиты, конференции, митапы, хакатоны, бизнес- и карьерные встречи. Продукт — агрегатор вакансий и событий. События — нетворкинг: там знакомятся с командами, которые нанимают.

Не делается на этом этапе: регистрация и RSVP через платформу, заявки организаторов, посты в канал Telegram.

## 26.2 Данные

- Таблица `events`: slug, название, описание (простой текст), `starts_at`/`ends_at` (timestamptz), IANA-пояс или `all_day`, формат `online`/`offline`/`hybrid`, страна (ISO 3166-1 alpha-2), город, ссылка организатора, приём докладов (ссылка и срок), темы (`web3`, `ai`, `dev`, `data`, `security`, `devops`, `product`, `design`, `business`, `career`), вид (`summit`, `conference`, `meetup`, `hackathon`, `business`, `career`), источник + внешний id (уникальны вместе), статус `published`/`removed`/`expired`, `last_seen_at`.
- RLS deny-all, доступ только `app_rw` на сервере.
- Прошедшие события получают `expired`, строки не удаляются.

## 26.3 Источники

- Только официальные открытые данные с лицензией на показ, с атрибуцией и ссылкой на организатора. Скрейпинг HTML запрещён (D18).
- Живой источник включается записью основателя в MISSION_LOG (`founder approved: republish allowed — <источник>`) и именем в `EVENTS_IMPORT_SOURCES`.
- Один источник за вызов cron, интервал источника, незавершённый прогон закрывается через 15 мин (как D412).

| Источник                | Данные                                                  | Лицензия                                   | Статус                          |
| ----------------------- | ------------------------------------------------------- | ------------------------------------------ | ------------------------------- |
| confs.tech              | `tech-conferences/conference-data`, JSON по теме и году | MIT                                        | код есть, выключен до одобрения |
| ethereum.org            | API Geode Labs по ключу (в репозитории только мок)      | MIT репозитория на эти данные не действует | не подключён, OPEN QUESTION     |
| Luma, Eventbrite, Apify | —                                                       | —                                          | запрещены                       |

## 26.4 Страницы

- `/events`: фильтры тема, вид, формат (онлайн включает гибрид, офлайн тоже), страна, даты «с» и «по», поиск по названию; по 24 на страницу; прошедших нет.
- `/events/[slug]`: когда, где, формат, вид, темы, ссылка на организатора (`rel="noopener noreferrer"`), приём докладов, атрибуция источника, Event JSON-LD (только для предстоящих), хлебные крошки. Прошедшее событие открывается с пометкой и `noindex`.
- В карте сайта — `/events` и предстоящие события.

## 26.5 Spoki

- `find_events` — только чтение, гостю тоже. Темы, вид, страна и «удалённо» берутся из вопроса или из известного профиля. Ответ — данные события как `<untrusted_data source="event:…">`, без внешних ссылок; ссылку даёт карточка `offer_step` → `/events`.
- Промпт v14: на вопрос про события — `find_events`; в поиске работы — один раз и не на ходу поиска можно предложить одно подходящее событие. Не выдумывать события. Регистрации на сайте нет.
