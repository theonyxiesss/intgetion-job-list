## 2. Разрыв и этапы

Порядок — по доверию сторон и зависимостям. Этапы A1–A4 не связаны с деньгами и юристом: их можно делать сразу после команды. Этапы B — с деньгами. Этапы C — с документами, налогами и фиатом.

## 3. Что предлагается первым

1. Довести B1 до прототипа в тестовой сети (ТЗ 43, шаг 2б), когда основатель подготовит тестовые кошельки.
2. Параллельно A1 (переписка в заказе) — не требует денег и юриста, нужна для споров B2.
3. Затем A2 и A3.

Это предложение; порядок выбирает основатель.

## 4. Решения основателя

- Подтвердить порядок A → B → C или другой.
- Для A1: хранить ли сообщения как переписку Spoki (24 часа, D471) или дольше — для споров нужна история. Это вопрос хранения персональных данных.
- Для A3: одна лента с вакансиями или отдельный раздел «Задачи».
- Для B и C: см. ТЗ 43 §6 и вопросы к юристу (D465).

## 5. Критерии «на уровне Upwork»

Цель считается достигнутой, когда на платформе можно пройти без выхода с неё: найти исполнителя или задачу → договориться в переписке → оплатить с удержанием → сдать и принять по этапам → решить спор → оставить отзывы с обеих сторон → видеть рейтинг. C1–C5 — по отдельным решениям основателя.

## 6. Что не входит автоматически

- Начало любого этапа без команды основателя.
- Хранение денег платформой, горячий кошелёк платформы.
- Фиат, карты, проверка документов без решения и юриста.
- Копирование кода или текстов Upwork.
