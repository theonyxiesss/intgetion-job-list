# 53. Chat-first: вся платформа через чат

> Статус: черновик ТЗ, ждёт решения основателя. Визуальный ориентир — прототип Morrow (`github.com/1egac1/h-ta`).
> Карта: [INDEX.md](INDEX.md) · бот сейчас: [../how-it-works/bot.md](../how-it-works/bot.md).

## 1. Цель

Главный интерфейс INTGETION JOB LIST — один чат. Всё, что сейчас делается через страницы (поиск вакансий, отклики, профиль, фриланс, события, тарифы, кабинет работодателя), пользователь делает в диалоге: пишет словами или нажимает интерактивные карточки внутри ленты сообщений.

Других интерфейсов нет: все старые страницы платформы убираются, их адреса открывают чат с нужной карточкой (раздел 9). Каждый сервис, включая вход и оплату, работает в чате интерактивно (раздел 5). Админка не меняется.

## 1a. Решения основателя (2026-11-06)

| Вопрос                                  | Решение                                                                                                |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Где запускать                           | Главная `/` — это чат. Вся платформа работает только через чат, отдельных страниц для действий нет     |
| Дизайн                                  | Как в Morrow: шрифт DM Sans, палитра, панель, карточки, анимации — без адаптации под чёрно-белый стиль |

| Гость                                   | Может делать часть действий без входа (раздел 5a)                                                      |
| Классические страницы как переключатель | Не делаем                                                                                              |

## 1b. Что умеет макет Morrow (проверено вручную)

Всё работает внутри чата, без перехода на страницы:

- Пустой экран: логотип, приветствие, поле ввода, кнопка «О Morrow».
- Левая панель появляется после первого сообщения: «Новый чат», «Найти работу», «Найти фриланс», список диалогов с поиском и удалением, профиль, «Очистить сессию», «Сохранённое» со счётчиком, «Прикрепить CV», переключатель темы.
- Текстовый запрос («frontend, React, TypeScript, remote») → 3 карточки вакансий: логотип, должность, компания, локация, тип, зарплата, метка «For you», «View details», «Save».
- «View details» раскрывает одну карточку на месте, остальные прячутся; внутри «Prepare application».
- «Подготовить отклик» → черновик сопроводительного письма в чате, кнопка копирования.
- Профиль в диалоге поверх чата: имя, роль, навыки, локация, CV, ссылка на портфолио. После сохранения рекомендации в старых сообщениях пересчитываются.
- Плашка «для персональных рекомендаций зарегистрируйтесь и добавьте CV», пока профиля нет.
- «Сохранённое» показывает сохранённые вакансии сообщением в чате.

Ограничения макета: данные — фиксированный список, ответы — правила по ключевым словам, без ИИ, всё хранится в `localStorage`. Тест концепции заменяет это на реальные данные и бота платформы.

## 2. Принципы

1. **Чат — это главная и единственный интерфейс.** `/` открывает чат. Отдельных страниц для действий нет.
2. **Действие = карточка.** Ассистент не только отвечает текстом, а возвращает живые компоненты: вакансию, форму, список, подтверждение. Пользователь кликает, не обязан печатать.
3. **Запись только после подтверждения.** Любое изменение данных (отклик, публикация, оплата, удаление) идёт через карточку подтверждения. Сохраняется существующее правило бота: факты берутся только от человека.
4. **Тот же сервисный слой.** Чат вызывает `src/modules/<m>/service/index.ts` через инструменты бота. Никакой второй бизнес-логики.
5. **Работает без ИИ.** Быстрые кнопки и команды (`/jobs`, `/apply`) дают результат даже при недоступной модели.
6. **Гость видит пользу сразу.** Поиск вакансий, фриланса и событий — без регистрации; регистрация предлагается в момент записи.

## 3. Структура экрана (по макету Morrow)

| Быстрые разделы панели       | Найти работу · Найти фриланс · События · Сохранённое · Мои отклики · Для работодателя (по роли)        |
| Центр, пустой чат            | Приветствие по центру, капсула ввода, 3 вкладки подсказок (D408/D409)                                  |
| Центр, активный чат          | Лента сообщений, карточки, индикатор «печатает», автоскролл                                            |
| Капсула ввода                | Текст, прикрепить файл (CV, портфолио), микрофон-заглушка (подсказка «Голосовой ввод скоро»), отправка |
| Плашка персонализации        | «Для точных рекомендаций войдите и добавьте CV» — пока нет профиля                                     |
| Диалог профиля               | Быстрое редактирование профиля поверх чата (как `profile-dialog` в макете)                             |

Темы: тёмная и светлая, переключатель в панели. Мобильная версия: панель — выезжающее меню, капсула прижата к низу.

Анимации из макета (framer-motion): появление сообщений, раскрытие карточки вакансии, сворачивание панели. Обязательно учитывать `prefers-reduced-motion`.

## 4. Каталог интерактивных карточек

Каждая карточка — React-компонент с типом в ответе бота (`offer_step` расширяется до общего `card`). Карточки состояния (сохранено, откликнуто) обновляются на месте без нового сообщения.

| Карточка                               | Где используется                   | Действия на карточке                                          |
| -------------------------------------- | ---------------------------------- | ------------------------------------------------------------- |
| `job` (список из 3 + «показать ещё»)   | поиск вакансий, `/matches`         | Раскрыть, сохранить, откликнуться, скрыть, «почему подходит»  |
| `job_detail` (раскрытая)               | раскрытие вакансии                 | Полное описание, зарплата, компания, откликнуться, поделиться |
| `freelance_task` / `freelance_service` | фриланс                            | Откликнуться с ценой и сроком, заказать услугу                |
| `event`                                | события Web3 и IT                  | Добавить в календарь, перейти                                 |
| `company`                              | компании                           | Вакансии компании, подписаться                                |
| `profile_snapshot`                     | после загрузки CV                  | Уровень, роль, навыки, «уточнить», «сохранить в профиль»      |
| `form` (универсальная)                 | черновик вакансии, услуги, профиля | Поля с текущими значениями, правка инлайн                     |
| `confirm`                              | любая запись                       | Подтвердить / Изменить / Отмена                               |
| `application_status`                   | мои отклики                        | Статус, история, отозвать                                     |
| `applicants`                           | работодатель                       | Список кандидатов, сменить статус отклика                     |
| `pricing`                              | тарифы                             | Сравнение, выбрать тариф → оплата                             |
| `payment`                              | оплата                             | Сумма, способ, переход в платёжную форму (вне чата, кнопкой)  |
| `salary`                               | зарплаты                           | Диапазон по роли и стране                                     |
| `notice`                               | системное                          | Ошибка, нужен вход, лимит тарифа                              |

## 5. Все сервисы в чате — интерактивно

Правило: **каждый сервис платформы полностью работает внутри чата.** Ни одно действие не уводит на другую страницу. У каждого сервиса есть три входа: кнопка в панели, текстовый запрос и кнопка на карточке. Результат — живая карточка в ленте, которую можно нажимать, редактировать, листать и подтверждать на месте.

| Сервис (модуль)                              | Как открыть                                           | Интерактивный сценарий в чате                                                                                                                                                                                                |
| -------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Вход и регистрация** (`auth`)              | «Войти» в панели, или любое действие, требующее входа | Карточка входа в ленте: email → код из письма вводится в той же карточке; кнопки Google и кошелёк (WalletConnect) открывают окно провайдера поверх чата и возвращают в ту же переписку. Сброс пароля, выход — тоже карточкой |
| **Онбординг** (`users`, `candidates`)        | Первый вход                                           | Пошаговые вопросы карточками: кто вы (кандидат / работодатель / фрилансер), роль, навыки-чипы, локация, удалёнка, зарплата. Каждый шаг можно вернуть назад                                                                   |
| **Профиль и CV** (`candidates`)              | «Мой профиль», прикрепить файл                        | Загрузка CV → `profile_snapshot` (уровень, роль, навыки) → правка чипов на месте → `confirm`. Портфолио: ссылки и работы списком с добавлением и удалением                                                                   |
| **Поиск вакансий** (`jobs`, `taxonomy`)      | «Найти работу», текст                                 | Карточки `job` по 3 + «Ещё»; фильтры чипами над списком (удалёнка, страна, зарплата, уровень, тип) — нажатие пересчитывает список в той же карточке                                                                          |
| **Подбор** (`matching`)                      | «Для меня»                                            | Карточки с процентом совпадения и раскрываемым «Почему подходит»                                                                                                                                                             |
| **Вакансия подробно**                        | «Подробнее» на карточке                               | Раскрытие на месте: описание, требования, зарплата, компания, «Откликнуться», «Сохранить», «Скрыть», «Поделиться»                                                                                                            |
| **Отклик** (`applications`)                  | «Откликнуться»                                        | Карточка: выбрать CV, черновик письма (сгенерировать, править прямо в карточке), ответы на вопросы работодателя → `confirm` → статус                                                                                         |
| **Мои отклики**                              | «Мои отклики»                                         | Список `application_status` со статусами и историей; «Отозвать» → `confirm`                                                                                                                                                  |
| **Сохранённое**                              | «Сохранённое» (счётчик)                               | Список сохранённых вакансий и задач с теми же кнопками; удалить из сохранённого                                                                                                                                              |
| **Сохранённые поиски** (`saved-searches`)    | «Сохранить этот поиск» над результатами               | Карточка подписки: частота, канал (email / Telegram) → `confirm`; список подписок с выключателями                                                                                                                            |
| **Утренние сводки** (`notifications`)        | Приходят сами                                         | Сводка новых вакансий сообщением в чате с карточками                                                                                                                                                                         |
| **Уведомления**                              | Колокольчик в панели                                  | Лента событий в чате (новый статус отклика, ответ работодателя); переключатели каналов в карточке `form`                                                                                                                     |
| **Фриланс: задачи** (`freelance`)            | «Найти фриланс»                                       | Карточки задач, фильтры; «Предложить» → цена, срок, текст в карточке → `confirm` (D569)                                                                                                                                      |
| **Фриланс: услуги и заказы**                 | «Мои услуги», «Создать услугу»                        | Черновик услуги заполняется по шагам в карточке (D493) → модерация; заказы со статусами и кнопками принять / сдать / завершить                                                                                               |
| **События** (`events`)                       | «События»                                             | Карточки `event`, фильтры по теме и стране, «В календарь», «Пойду»                                                                                                                                                           |
| **Компании** (`companies`, `follows`)        | Логотип на карточке, текст                            | Карточка `company`: описание, вакансии компании списком, «Подписаться»                                                                                                                                                       |
| **Зарплаты** (`salaries`)                    | «Сколько платят …»                                    | Карточка `salary`: диапазон, медиана, переключатели роли, страны и уровня                                                                                                                                                    |
| **Отзывы и контент** (`ugc`)                 | «Оставить отзыв о компании»                           | Форма отзыва в карточке → `confirm` → модерация                                                                                                                                                                              |
| **Контакты** (`contacts`)                    | «Связаться»                                           | Карточка обратной связи, ответ приходит в этот же чат                                                                                                                                                                        |
| **Обратная связь** (`feedback`)              | 👍/👎 под ответом, «Сообщить о проблеме»              | Короткая форма в карточке                                                                                                                                                                                                    |
| **Работодатель: вакансии** (`jobs`)          | «Опубликовать вакансию»                               | Черновик по шагам (D494), предпросмотр карточки как увидит кандидат → `confirm` → модерация. «Мои вакансии»: статус, редактировать, закрыть, продлить                                                                        |
| **Работодатель: кандидаты**                  | «Кандидаты»                                           | Карточка `applicants`: список, раскрыть профиль и CV, сменить статус кнопкой → `confirm`, написать кандидату                                                                                                                 |
| **Работодатель: кампании**                   | «Кампании»                                            | Карточка кампании: бюджет, срок, вакансии → `confirm` → статистика в той же карточке                                                                                                                                         |
| **Тарифы и оплата** (`billing`)              | «Тарифы»                                              | Карточка `pricing` со сравнением → выбор → `payment` (сумма, способ) → платёж в окне провайдера поверх чата → чек и статус подписки сообщением                                                                               |
| **Настройки и аккаунт** (`users`, `privacy`) | «Настройки»                                           | Карточка `form`: язык, тема, уведомления, приватность; экспорт данных и удаление аккаунта — через `confirm` с повторным вводом                                                                                               |
| **Отписка**                                  | Ссылка из письма                                      | Открывает чат с карточкой «Вы отписаны» и кнопкой «Вернуть»                                                                                                                                                                  |
| **Подключение ИИ-ассистента** (`mcp`)        | «Подключить ассистента»                               | Карточка: персональные токены (создать, скопировать, отозвать), подключённые клиенты; OAuth-согласие — карточкой                                                                                                             |
| **Юридические тексты**                       | Ссылка в панели                                       | Текст открывается в чате как сообщение-документ; адреса `/privacy`, `/terms` для поисковиков остаются                                                                                                                        |
| **Голос**                                    | Кнопка микрофона                                      | Заглушка «скоро»                                                                                                                                                                                                             |

**Админка не входит в эту переделку.** Админ-панель (`admin`, `admin-console`, `moderation`, `metrics`, `analytics`) остаётся как есть: свои страницы, свой адрес и хост, без изменений кода и дизайна.

Общие требования к интерактивности:

- Карточка обновляется на месте, без нового сообщения (сохранено, статус сменился, фильтр нажат).
- Любое поле в карточке можно править прямо в ней; бот подхватывает изменения.
- Длинные списки — «Ещё» внутри карточки, а не новое сообщение.
- Окна сторонних провайдеров (OAuth, оплата) открываются поверх чата и возвращают в ту же переписку и то же действие.
- Каждое действие доступно кнопкой без ИИ; текст — дополнительный способ.

## 5a. Что доступно гостю

| Без входа                                                                    | Только после входа                        |
| ---------------------------------------------------------------------------- | ----------------------------------------- |
| Поиск вакансий, фриланса, событий, компаний, зарплат                         | Отклик на фриланс-задачу, заказ услуги    |
| Раскрытие карточки, «почему подходит»                                        | Публикация вакансии и услуги              |
| Сохранение (в браузере, переносится в аккаунт при входе)                     | Мои отклики и их статусы                  |
| Черновик сопроводительного письма                                            | Профиль на сервере, загрузка CV в аккаунт |
| Отклик на вакансию с email и CV, если работодатель разрешил гостевые отклики | Тарифы, оплата, уведомления, настройки    |

Когда гость нажимает действие из правой колонки, в чате появляется карточка `notice` «Войти», после входа он возвращается в тот же чат и действие продолжается.

> Уточнить у основателя: гостевой отклик на вакансию — как в таблице (по разрешению работодателя) или другое правило.

## 6. Работодатель

Тот же чат, но режим определяется ролью аккаунта. В панели раздел «Для работодателя»: опубликовать вакансию, мои вакансии, кандидаты, тариф. Смена статуса отклика — только через `confirm`. Набор статусов не меняется (D2).

## 7. Данные и хранение

- Чаты хранятся на сервере у вошедшего пользователя (сейчас `GET /api/bot/conversation`), у гостя — в браузере, при входе переносятся в аккаунт.
- Сохранённое, отклики, профиль — существующие таблицы, без дублирования.
- Состояние карточки берётся из БД при рендере, а не из текста сообщения, чтобы старый чат показывал актуальный статус.
- Загрузка CV: файл в хранилище Supabase, разбор на сервере, результат — `profile_snapshot`, запись в профиль только после `confirm`.

## 8. Telegram

Тот же набор инструментов. Карточки, которые Telegram не может показать, отдаются текстом с кнопками и ссылкой `/chat?confirm=<id>` (как сейчас).

## 9. SEO и старые страницы

- Все страницы платформы убираются. Их адреса открывают главную-чат с нужной карточкой: `/jobs/<id>` → чат с раскрытой карточкой `job_detail`, `/applications` → чат с «Мои отклики», `/pricing` → карточка `pricing` и т.д. Старые ссылки и закладки продолжают работать.
- Отдельных страниц не остаётся, кроме админки: вход, регистрация и юридические тексты тоже открываются в чате (раздел 5). Админка не трогается. Служебные адреса для провайдеров (`/auth/callback`, `/oauth`) только возвращают в чат.
- Переключателя «классический вид» нет.
- SEO: адреса вакансий, компаний и событий отдают с сервера заголовок, описание и разметку `JobPosting` той сущности, а интерфейс — чат с её карточкой. Sitemap сохраняет эти адреса. Без этого вакансии пропадут из Google.

## 11. Нефункциональные требования

- Ответ первого символа ≤ 2 с, карточки без ИИ (кнопки) ≤ 500 мс.
- Доступность: навигация с клавиатуры, aria-метки карточек, контраст в обеих темах (axe в CI).
- Все строки через `src/messages/{en,ru}.json`.
- Lighthouse главной не хуже текущего порога CI.
- Ошибки модели: понятная карточка `notice` + кнопки, а не пустой ответ.

## 12. Метрики успеха

- Доля пользователей, сделавших целевое действие (сохранение, отклик, публикация) в первой сессии.
- Время от входа до первого отклика.
- Доля действий через карточки против ввода текста.
- Отказы на пустом экране чата.
