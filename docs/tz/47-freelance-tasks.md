## 2. Как устроено

**Задача** (`freelance_tasks`): заказчик (сам или от компании) описывает работу: название 10–120 знаков, описание 80–2000, категория из `FREELANCE_CATEGORIES`, бюджет «от–до» в долларах или «договорной», «когда нужно» до 80 знаков. Без контактов (`hasContacts`).

Статусы: `pending` (на проверке) → `open` (видна в разделе 30 дней) → `hired` (выбран исполнитель) | `closed` (заказчик закрыл) | `expired` (30 дней прошло) | `rejected` (модератор отклонил).

**Отклик** (`freelance_proposals`): исполнитель (у кого включён режим исполнителя) предлагает цену ($10–$20 000), срок (1–90 дней) и сопроводительный текст 40–2000 знаков без контактов. Один отклик на задачу от одного исполнителя. Статусы: `sent` → `accepted` | `declined` | `withdrawn`.

**Выбор:** заказчик принимает отклик → в одной транзакции создаётся заказ (`freelance_orders`) сразу в статусе `accepted` (обе стороны уже согласились) со снимком: название задачи, цена и срок отклика, описание задачи как задание, одна правка; задача → `hired`; остальные отклики → `declined`. Дальше работает обычный путь заказа: оплата (D463, потом эскроу ТЗ 43), переписка (ТЗ 45), сдача, приёмка, отзывы с обеих сторон (ТЗ 46).

**Видимость:** раздел и страница задачи — для всех (гостю — без кнопки отклика); имя заказчика не показывается (как в отзывах: «человек» или «компания»); сводка о заказчике из ТЗ 46 видна исполнителям. Отклики видит только заказчик задачи и сам автор отклика.

**Лимиты:** 3 задачи в сутки на аккаунт, 20 откликов в сутки (`rateRules`).

## 4. Критерии приёмки A3

- [ ] Задача публикуется только после модератора; с контактами — 422.
- [ ] Свою задачу откликнуть нельзя (409); второй отклик — 409; отклик на закрытую — 409.
- [ ] Принятие отклика создаёт заказ `accepted` с ценой и сроком отклика; задача `hired`; прочие отклики `declined`; повтор — 409.
- [ ] Отклики видит только заказчик задачи и автор отклика; чужим — 404.
- [ ] Через 30 дней задача `expired` (крон фриланса).
- [ ] Новый отклик уведомляет заказчика, принятый — исполнителя; email следует пользовательским настройкам уведомлений.
- [ ] Spoki показывает карточки только найденных открытых задач; отправка отклика требует карточку подтверждения с ценой, сроком и текстом от пользователя.
- [ ] Sitemap включает раздел задач и открытые публичные задачи.
- [ ] `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm build`; интеграционные — в CI после `0073`.

## 5. Решения основателя

1. **Решено D569:** одна правка в заказе из принятого отклика.
2. Нужна ли платная «закреплённая» задача (сейчас нет).
3. Показывать ли заказчику число откликов других (сейчас — только свои отклики видит исполнитель).

## 6. Что не входит

- Почасовая оплата, вопросы к заказчику до отклика (вопросы — в переписке после выбора), приглашение исполнителя (A4).

## 7. Выпуск

- Миграция `0073`, push и выкладка — по «да» основателя. До применения `0073` раздел показывает «скоро будет», API отвечает 503 `TASKS_NOT_READY`.
