## 2. Что осталось

1. **Живая проверка под входом** — ждёт снятия ограничения Supabase (квота трафика). Блокер: внешний, не код.
2. **Успешный путь услуги** — нужна опубликованная услуга, созданная штатно через форму и модерацию. Блокер: решение основателя (создать тестовую запись) и вход.
3. **Мобильная проверка** — 390 px и клавиатура при вводе. Блокер: вход на телефоне или эмуляция в браузере. Можно сделать без входа на гостевой странице.
4. **CI integration/e2e** — блокер: push ветки, а это по правилам «да» основателя.

## 4. Что не входит

- Новая персистентность или новая таблица.
- Изменение срока хранения переписки (D471).
- Новые блоки и новые компоненты (это этап 4).
- Изменения модели или промпта (это этап 2).
- Внешний поиск (этап 5).

## 5. Правила выпуска

- Commit — только по «да» основателя. Сейчас коммит локальный, только файлы этапа.
- Push и выкладка на production — отдельное «да». Выкладка не нужна, чтобы закрыть проверку на localhost.
- Миграций в этом этапе нет. Если понадобится — отдельное ТЗ и «да».
