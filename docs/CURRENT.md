# CURRENT — состояние сейчас

**Направление Spoki (основатель, 2026-10-25):** сохранить план агента для всей платформы: вести цель человека через вакансии, фриланс, UGC, услуги, события и профиль; самостоятельно координировать шаги и помогать согласовывать условия. Поиск начинается с платформы, внешний — после согласия при отсутствии подходящего результата. План развития: состояние цели → межсервисные сценарии → интерактивные сравнения/формы/прогресс → согласование действий → сопровождение и напоминания → внешние источники и надёжность. Это направление развития, не готовая функциональность и не разрешение на автоматические обязательства перед другими людьми. D538 добавил локально ход работы инструментов, интерактивные уточнения, состояния ошибок и блокировку параллельных действий карточек. Живой запрос услуги теперь показывает шаг услуг и ответ об отсутствии результатов без карточек вакансий. Остаётся проверить мобильный интерфейс, сценарий вошедшего пользователя и восстановление прогресса; до этого выкладка не готова.
