# Разбор CryptoJobsList (cryptojobslist.com), 2026-10-04

Цель — не отставать по разделам, категориям и подаче. Ниже: что у них есть, чего нет у нас, что брать и куда. Используется для правки `docs/DESIGN.md` и `docs/MARKERS.md` (D202).

## 1. Что у них есть

### Главная = каталог

- Заголовок «The Biggest List of Crypto, Blockchain and Web3 Jobs», в `<title>` — «82 new in Oct 2026» (свежесть как аргумент), под списком «Updated 9 hours ago».
- Лента логотипов нанимающих компаний (Trezor, Chainlink, CoW DAO…) — социальное доказательство.
- 58 тегов-чипов (первые ~27 видны, остальное — «Show more»): «For you» (персонально, с красной точкой), Remote, Web3, Non Technical, NFT, Solidity, Developer, Marketing, DeFi, Internships, Entry Level, Compliance, Community, Designer, Trading, Zero Knowledge, Ethereum, Solana, Rust, Legal, AML, Content Writer, C++, React, HR, Content, Memes, UI/UX, GameFi, DevRel, iOS, Java, Data Analyst, Venture Capital, Quant, Event Marketing, Engineering, Data, Fantom, Smart Contract, Economist, Metaverse, Substrate, Kubernetes, Machine Learning, Open Source, Technical Writer, Full-stack, Django, Translator, Manager, Analyst, Ruby on Rails, Copywriter, Contract, SRE, Freelance. **Каждый тег — отдельная страница** (`/solidity`, `/defi`, `/zk`, `/non-tech`) — это их SEO.
- Поиск + «Location, Remote», сортировка, панель фильтров: предпочтительный часовой пояс, Remote, вилка зарплаты (час/неделя/месяц/год).
- Карточка: логотип, название, компания, зарплата («45k-90k/year»), локация, 3–5 тегов. «Load more» + пагинация, «You viewed 25 out of 376». Закладки.
- Ниже — ссылки на страницы стран (12), городов (28), регионов (10), блок «Hiring?», **FAQ** (8 вопросов), всплывашка «Get real-time job alerts on Telegram», баннер куки с одной кнопкой «Okay».

### Страница вакансии

- «⭐ Featured Opportunity» (платное продвижение), «Posted by», дата.
- Описание: обязанности, требования, **Perks** (оплата в крипте, токены с вестингом, доля в кооперативе).
- **Вопросы работодателя** при отклике (до 3, «no AI use, we check»).
- Теги, включая «Pay In Crypto»; зарплата; **«133 applications»** (счётчик откликов).
- «Discuss on Telegram / X», «Report».
- **FAQ по вакансии** (сколько платят, удалённо ли, какие навыки, полная ли занятость, как откликнуться) — генерируется, для SEO.
- «Related Salaries» (по типу занятости, роли, сфере, «Pay-In-Crypto») и «Related Locations».

### Работодателю (`/hire`)

- Самостоятельная публикация **за деньги** ($200, оплата BTC/ETH/USDC/DOGE), аукцион позиции в списке, 30 дней, рассылки в X, newsletter, LinkedIn, Discord, Telegram (по 4 раза).
- **Вилка зарплаты обязательна**; скрыть от публики — за доплату.
- Видео-описание вакансии, видео-отклики, обязательное CV, до 3 скрининг-вопросов; по умолчанию у кандидата спрашивают cover letter, CV, GitHub, LinkedIn, Telegram, текущую зарплату, локацию, телефон.
- Бесплатный ATS-дашборд, пакеты вакансий, рекрутинг за success fee, модерация всех объявлений и проверка юрлица.

### Кандидатам и сообщество

- **Зарплаты** (`/salaries`): анонимная подача (без аккаунта, модерация, 11 % отклоняют), средняя $84k, P10/P90, разбивка по ролям и городам, калькулятор.
- **Talent** (`/talent`): 35 тыс. профилей — доступность, часовой пояс, «In crypto since 2017», языки, навыки, ставки после входа.
- Trends, Platform Activity (stats), Layoffs-трекер, Research, Events, Blog, Newsletter, Telegram-бот вакансий, X Spaces, Success Stories, курсы, амбассадоры, API, «Verify Official Accounts», **DPRK Check** (проверка на северокорейских «IT-работников»), набор утилит (крипто-калькулятор зарплаты, payslip/invoice-генераторы, blind CV, Wordle).

## 2. Где мы уже сильнее

- Подбор с объяснением «почему подходит» (6A/6B) и «Не подходит» с обучением — у них «For you» без объяснений.

- Бот-онбординг (7A/7B), RU/EN, WCAG AA, экспорт и удаление данных (10C).

## 3. Что брать — приоритеты

**P1 — в дизайн-ТЗ сейчас (вписывается в MVP, без новых сущностей кроме D202):**

1. Теги-чипы с «Показать ещё» и персональной кнопкой «Для вас» с точкой `--signal`, когда есть новые совпадения — уже в `MARKERS.md` п. 7; добавить «Показать ещё» после 2 рядов.
2. **Страницы тегов**: `/jobs/t/[slug]` (сфера, навык, роль, уровень) — тот же каталог с предустановленным фильтром, свой H1 и `<title>` («Вакансии Solidity — удалённо»), в sitemap. Это главный канал трафика у них.
3. Свежесть: в `<title>` и под заголовком каталога — «N новых за месяц», «обновлено X назад» (mono, `--fg-subtle`).
4. Лента логотипов компаний с опубликованными вакансиями на главной (только verified, без картинок-заглушек; если логотипов < 4 — блок скрыт).
5. Карточка: зарплата первой строкой телеметрии, бейдж «Оплата в крипте», до 3 тегов + «+N».
6. Страница вакансии: блок «Условия» (perks), счётчик откликов («N откликов», только если ≥ 5 — не пугать нулями), «Пожаловаться» уже есть, блок FAQ по вакансии (собирается из полей, без LLM), «Похожие вакансии» по сфере/навыкам.
7. **FAQ на главной** (6–8 вопросов: как работает подбор, бесплатно ли, как защищены контакты, что такое Web3-вакансии, как попасть без опыта) — текст от основателя (OPEN QUESTION для формулировок).
8. Страница «Для работодателей» — описание процесса публикации и верификации, без цен.

**P2 — после MVP, отдельные подфазы:**

9. Раздел «Зарплаты» из наших же вакансий (медиана, P10/P90 по роли/сфере/уровню, только при n ≥ 10) — анонимная подача позже.
10. Публичная статистика и тренды (число вакансий по сферам за месяц) — из представлений 18.2.
11. Страницы по часовым поясам и регионам (`/jobs/r/europe`, `/jobs/tz/utc+3`) — у нас это сильнее локаций.
12. Скрининг-вопросы работодателя (до 3) при отклике; рассылка/Telegram-оповещения — по 9B и V2 Telegram.

**P3 — V2/V3 по ТЗ (раздел 21), не делать сейчас:**

13. Платная публикация, featured, аукцион позиций, пакеты — V3 (подписки/featured).
14. База талантов для работодателей — V3.
15. Видео-описания и видео-отклики, CV upload — V2.
16. Утилиты, блог, события, курсы, layoffs, API — маркетинг, вне продукта.
17. Проверка кандидатов на DPRK-схемы — идея для risk-флагов 14.3 (кандидаты), обсудить отдельно.

## 4. Чего не копировать

- Зарплату как обязательное поле — у нас по ТЗ она может отсутствовать (`×0.95` в подборе); можно показывать «Зарплата не указана» и поднимать вакансии с вилкой. Решение — основателю.
- Баннер куки с одной кнопкой — у нас уже два равных выбора (D201).
- Всплывающие окна поверх списка («Join Telegram») — противоречат DESIGN 6.7 и бюджету LCP.
- Сбор телефона и текущей зарплаты по умолчанию — противоречит приватности (5.3, D3).
