## 1. LCP главной (сначала это)

В CI главная держится на грани бюджета 2500 мс: медианы 1973–2506 мс, задача `database` падает без причины в коде. Цель — медиана ≤ 2200 мс стабильно.

- LCP-элемент — вторая строка героя: `<span class="ui-rise block [--i:1]">` в `src/app/[locale]/page.tsx`. TTFB ~460 мс, FCP ~920 мс, а **render delay 1.4–2.1 с**. Смотри: анимацию `ui-rise` с `animation-delay` (`globals.css`, `--d-slow`), загрузку шрифта `Roboto_Condensed` (подмена шрифта делает новый LCP-кандидат), клиентский JS на главной.
- Claude Code добавил в тот же файл `generateMetadata` в начало — не трогай его, работай с вёрсткой героя ниже.
- Меряй как CI: prod-сборка, 5 прогонов Lighthouse, медиана (скрипт в `.github/workflows/ci.yml`). В отчёте — до/после по каждому прогону.
- Внешний вид героя заметно не меняем. Если анимацию нужно убрать или упростить — опиши это решением D280.

## 2. Отдельный адрес админки `admin.intgetion.com`

DNS и домен в Vercel делает основатель. Твоя часть — чтобы включение прошло за 5 минут:

- В `docs/RUNBOOK.md` раздел «Включение admin.intgetion.com»: запись DNS (CNAME на Vercel), добавление домена в проект `intgetion-job-list`, переменные окружения, установка `ADMIN_HOST_ONLY=1`, проверки после (на `admin.intgetion.com` работает вход и MFA, всё прочее — 404, `robots.txt` — `Disallow: /`; на `intgetion.com/en/admin` — 404), откат (убрать флаг).
- Скрипт `scripts/check-admin-host.mjs` (проверки из списка выше по заданному хосту), запуск `pnpm admin:check-host <host>`.
- В отчёте — вопросы основателю из твоих OPEN QUESTION (периметр: IP / Cloudflare Access / только MFA; состав команды и роли; HIBP), каждый с твоей рекомендацией.
- Флаг на проде не включай.
