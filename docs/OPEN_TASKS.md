## PLANNED (решение основателя 2026-10-07, не начинать без команды)

### Языки сайта: адреса без `/en` + новые языки

Решено: не определять язык по IP/провайдеру (VPN, экспаты, Googlebot с US-IP, риск cloaking) и не уходить в «только английский + Google Переводчик» (теряется русский SEO, письма/бот/ошибки не переводятся).

1. **Шаг 1 — адреса.** Английский на корне без префикса (`/jobs`), остальные языки с префиксом (`/ru/...`): next-intl `localePrefix: "as-needed"`. Первый заход на `/` — язык из `Accept-Language`, дальше выбор в куке + переключатель. Нужно: 301 со всех `/en/...`, sitemap, hreflang/canonical, ссылки в письмах (`render.ts`, `email-html.ts`, Supabase-шаблоны D330), Telegram-ссылки, e2e. Ожидать несколько недель переиндексации.
2. **Шаг 2 — новые языки, по одному и по данным** (Search Console, `/admin/metrics`: страны и языки браузера; порог ~10% трафика):
   - сначала испанский (`es`) и бразильский португальский (`pt-BR`) — крупнейшие рынки удалённой работы;
   - потом немецкий (`de`) и французский (`fr`);
   - итальянский (`it`) — последним.
3. **На каждый язык:** перевод `src/messages/*.json` (~1700 строк, машинный + вычитка носителем), письма и уведомления, ответы бота, юридические тексты (условия/политика — перевод человеком, GDPR для de/fr/it), проверка вёрстки на длинных строках (немецкий).
4. **Ограничение:** вакансии остаются на языке работодателя — переводится только интерфейс. Подумать, как это показать пользователю (метка языка вакансии / требование английского).
