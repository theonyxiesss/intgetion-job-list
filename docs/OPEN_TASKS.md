# Недоделанные задачи

Список того, что код уже не закрывает сам или ждёт живой проверки основателя. Не путать с OPEN QUESTION в ТЗ: здесь — конкретные хвосты после попыток фикса.

## Phone Mini App — кнопка меню бота

- **Статус:** ждёт живой проверки после D324 (выкладка). Если после D324 на телефоне по кнопке меню бота человек всё ещё гость — считать **незакрытым** и не крутить вход дальше без новых логов/`initData`.
- **Симптом:** Telegram Desktop / Web по кнопке меню входит; телефон — нет (гость, без сессии).
- **Уже пробовали:** D320 (Lax vs Partitioned), D321 (парсер `#/path?tgWebAppData`), D322 (bounce `/` без HTTP 307 + `sessionStorage` hash + `/tg.html`), D324 (официальный `telegram-web-app.js` + CSP `https://telegram.org` + stash raw init).
- **Наблюдение по логам (2026-10-07):** почти нет вызовов `/api/auth/telegram/miniapp` — клиент часто вообще не получает подписанную строку.
- **Что проверить основателю:** BotFather URL = `https://intgetion.com/tg.html`; полностью закрыть Mini App на телефоне и открыть снова кнопкой меню; сказать, вошёл ли в аккаунт.
- **Если снова нет:** прислать с телефона: пустой экран / экран входа / сайт без аккаунта; iOS или Android; URL в BotFather. Дальше — отдельная задача (возможно ручной вход через бота `login_*`, не Mini App auto-sign-in).
