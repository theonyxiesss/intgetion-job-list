### СРОЧНО — Supabase Auth HTTP 402 `exceed_egress_quota`

2026-10-29 прямые GET к Supabase Auth health/settings ответили 402; Google-вход на production вернулся с `oauth_unavailable`. Вход по email и завершение Telegram-входа зависят от того же Supabase Auth и при этом ограничении не могут работать. В кабинете владельца проверить Usage → Egress (включая разрез по сервисам), дату следующего цикла и организацию проекта. Для немедленного восстановления нужен переход Free → Pro от $25/мес; по документации ограничение также снимается при новом биллинговом цикле. Изменение тарифа — платное действие, требует отдельного согласия основателя. После снятия ограничения проверить по одному реальному входу через email, Google и Telegram, затем найти источник egress и поставить мониторинг. SQL-размер БД ~156 MiB к этой блокировке отношения не имеет.
